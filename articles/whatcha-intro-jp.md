はじめまして。グループ日記プラットフォーム「**Whatcha**（what-are-you-do-ing）」の公式アカウントです。

この記事では、Whatchaがどんなアプリなのかを紹介します。

ひとことで言うと、**大切な人と一冊の日記を共同で書き続けるためのアプリ**です。

## 「誰かが撮ってるだろう」で、消えていった思い出

イベントや旅行のあと、写真を集めようとしたことはありませんか。

やってみると、意外と誰も撮っていなかったり、逆に自分のスマホの中にしか残っていなかったりします。写真はそれぞれの端末に散らばり、機種変更やデータ整理で少しずつ消えていく。

数年後に見返そうとしたとき、「あの日」がもう残っていない。

Whatchaは、その経験から生まれました。

## 今のSNSが解決してくれないこと

InstagramやXはとても便利です。でも、そこにあるのは基本的に「**個人の投稿**」です。

同じ旅行に行っても、Aさんが撮った写真、Bさんが撮った動画、Cさんが感じたことは、それぞれ別々の場所に存在しています。ひとつの思い出として、みんなで育てる場所はあまりありません。

しかも、いいねや再生数といった「評価」が前提になっているので、本当に残したかった何気ない一日ほど、埋もれていきます。

- 写真がバラバラになる
- いいねのための投稿になってしまう
- 同じ体験なのに、一人の記録になってしまう
- 見返さなくなって、少しずつ薄れていく

## Whatchaという解決策

**一冊の日記を、みんなで育てる。**

Whatchaでは、ひとつのグループがひとつの日記を持ちます。

![グループごとに一冊の日記。表紙・説明・カレンダー・継続日数がひとつの画面にまとまる](notes-whatcha/images/01/01-diary-jp.png)

写真、文章、動画、場所、気持ち、音声。同じ日のページに、それぞれの視点が重なっていきます。誰か一人の記録ではなく、その場にいた全員の記録になる。

続ければ続けるほど、思い出は豊かになっていきます。

## Gitの思想で、思い出を安全に育てる

Whatchaのいちばん変わっているところは、**バージョン管理の仕組みをそのまま日記に持ち込んだ**ことです。

- **Version History** — 保存はすべてコミット。過去の記録をいつでも見返せる
- **Diff** — 誰がどこを書き足したのかが一目でわかる
- **Branch** — テーマやイベントごとに分けて記録できる
- **Merge** — バラバラだったみんなの記憶をひとつにまとめる
- **Pull Request** — 内容を確認してから、安心して共同編集できる

書き間違えても、消してしまっても大丈夫です。履歴をさかのぼって、いつでも元の状態に戻せます。

**上書きされて失われることが、ありません。** これは共同編集の日記にとって、思っている以上に大事なことでした。

## こんなふうに使われています

**カップル** — 二人だけのプライベートなタイムライン。遠距離、旅行、同棲、記念日。

**学校** — 学級日誌、文化祭、卒業アルバム。みんなの学生生活を一冊に。

**職場** — 社内イベント、プロジェクトの記録、新人研修。チームの歩みを未来へ。

## どこからでも書けます

iOS / Android / Web / macOS / Windows / Linux の6環境に対応しています。

朝はMacで書き、昼はiPhoneで写真を追加し、夜はWindowsのノートPCで振り返る。同じアカウントで、どこからでも同じ日記に書き足せます。表示言語は15言語に対応しています。

ログインはGoogle・Apple・Microsoftアカウントに対応、二段階認証も使えます。招待はリンク1本で、閲覧・編集の権限も管理できます。
