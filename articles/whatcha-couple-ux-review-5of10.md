こんにちは。交換日記アプリ [Whatcha](https://whatareyoudo.ing/?utm_source=zenn&utm_medium=article&utm_campaign=w_review) を個人で作っている LoveKapibarasan です。

先日、匿名のWさんから UX レビューをいただきました。「付き合って間もないカップルの片方（非エンジニア）が、2人で交換日記をつけたくてサイトを開いた」という立場で、日記の作成、2人用のグループ、招待リンク、投票、記念日、検索、スマホ幅の表示まで、最初から最後まで触ってもらったものです。スクリーンショットは89枚ありました。

総合評価は **10点中5点**、指摘は **19件** でした。

この記事は、開発者としてその19件をどう読み、どう課題（Issue）にして、何から直すかの記録です。レビューの全体と、Wさんへのお礼は note に書きました。

https://note.com/whatcha/n/n0af23a331119

## 前提：Whatcha は Git の考え方を日記に持ち込んだアプリ

Whatcha は、保存のたびに履歴が積まれ、書いたものが消えない交換日記アプリです。中身は Git の考え方そのもので、保存は commit、履歴は commit の列、2人の書き換えはマージで扱っています。

レビューでも「書いたものが消えない（履歴が残る）」というコンセプト自体は魅力的だと言ってもらえました。ただ、この「Git っぽさ」が、今回いちばん裏目に出ていたところでもあります。

## レビューの条件

レポートに明記されていた前提です。

- Chrome のデスクトップ幅（約1440px）と、モバイル幅（390×844）
- テスト用アカウントでログイン済みの状態から開始。未ログインの初回訪問と新規登録は対象外
- 招待を受け取る相手側のアカウントがないため、「パートナーが参加する」流れは未検証
- 読み込み時間は目視計測（±1秒程度）

19件のそれぞれに、重要度（High / Medium / Low）、再現手順、期待した動作、実際の動作、ユーザーへの影響、該当スクリーンショット、改善提案が付いていました。

## 19件を5つに分けて読む

### 1. 操作したあとに、何も返ってこない

いちばん重かったのはこれです。

- 日記を書いて「SAVE ENTRY」を押すと、数秒スピナーが回ったあと、何のメッセージもなく編集フォームのまま。保存できたかは、画面右上の小さな英数字（`84786c9` → `27a0ece`）が変わったことでしか分からない（High）
- グループを作っても、招待リンクをコピーしても、完了の表示がない。作った招待リンクは、画面を離れると再表示されない
- プロフィールのハンドルに日本語を入れて ✓ を押すと、何も言われずに元に戻る
- 記念日を日付なしで保存しようとすると、何も起きない
- グループのチャットを始めようとすると「Please check your input.」だけが出て、何を直せばいいか分からない（High）

![保存を押しても、何も表示されずに編集画面のまま](/images/whatcha-couple-ux-review-5of10/d34.jpg)

僕には、右上の英数字が変われば「保存できた」と読めます。commit の短いハッシュだからです。でもそれは、作った本人だから読める表示でした。

### 2. Git の言葉が、そのまま画面に出ている

「Blame」「Version Control」「Commit message」「Switch branch main @27a0ece」「Create Merge Request」「Issues」。最初のツアーでも「commit」「merge」「revert」で説明していました。保存のたびに「Commit message」の入力ダイアログも出ます。

![エントリ画面に並ぶ「Blame」「Version Control」](/images/whatcha-couple-ux-review-5of10/d26.jpg)

Wさんの言葉で、いちばんハッとしたのがここです。

> 恋人との日記に「Blame」ボタンがあるのは心理的にも抵抗がある

`git blame` は、僕にとっては「この行を誰が書いたか見る」コマンドの名前でしかありません。でも英語の blame は「責める・非難する」です。恋人と使う日記に置いていい言葉ではありませんでした。

レポートには言い換えの案も付いていました。「Blame」→「だれが書いた？」、「Version Control」→「書き直しの履歴」、「commit」→「保存」、「revert」→「この時点に戻す」。

### 3. 機能はあるのに、たどり着けない

- 2日目の日記の足し方が、日記の「Edit」画面の中にしかない。ふだんのカレンダーで日付を押しても何も起きない（High）
- 2人で書くには先に「グループ」を作る必要があるが、新規日記の画面からはそれが分からない。選べるのは「Personal (only you)」だけ
- グループに「Chat with this group」とあるのに、チャットにたどり着けない（High）
- モバイルのヘッダーに、ラベルのないアイコンが11個並んでいる
- 場所に「駅前のカフェ」と入れても、住所の欄も埋めないと地図に出ない。それが画面からは分からない

毎日書くアプリなのに、毎日書くための入り口が隠れていました。

### 4. ポップアップと広告

- 最初の数秒で、クッキー同意・ようこそツアー・ブラウザ通知の許可・プレミアムの案内・外部広告の5種類が同時に出る
- 「Facebookアカウントが乗っ取られたら…」「VPN とは…」のような外部広告が、閉じても次の画面でまた出て、ナビゲーションを覆う（High）

レポートの言葉では、プライベートな思い出を書く場所として「信頼しづらい」。ユーザーから見れば、出ているのは全部 Whatcha の画面です。

### 5. 表示の遅さと、ずれ

目視計測（±1秒）で、

- エントリの作成（OK を押してから画面が出るまで）：約7秒
- エントリの表示：約5〜7秒。その間はタイトルも本文もなく、「日記が消えた？」ように見える
- 新規日記の画面：約3秒
- 表示が終わる直前にパンくずが差し込まれて EDIT ボタンが下にずれ、押し損じる

一方で、ホームの再読み込みは約2秒、検索は約1秒で「速い」と書いてもらえていました。遅いのは、日記を開く・作るところに集中しています。

### そのほか

Story Mode で範囲の最終日の日記が含まれない（High）、日本語の検索で関係のない日記が混ざる、「保存」と「削除」のボタンが同じ大きさで隣り合っている、「1 entries」のような細かな文言、などです。

## なぜ作っている側には見えないのか

19件を読んで思ったのは、ほとんどが「毎日触っているのに、僕には見えていなかった」ものだということです。理由は3つあると思っています。

1. **言葉を知っている。** Blame も Commit も、僕には説明のいらない言葉です。違和感を覚えるきっかけがありません。
2. **場所を知っている。** 2日目の書き方もチャットの入り口も、どこにあるかを知っているので、探したことがありません。「見つからない」は、知らない人にしか起きません。
3. **最初の数秒を、もう体験できない。** ポップアップは一度閉じれば出てこなくなります。開発者の画面は、いつも「閉じたあと」の状態です。

保存したあとに何も出ないのも同じで、僕はハッシュの変化で「保存できた」と読めてしまう。自分のための表示が、そのまま全員向けの表示になっていました。

## 19件をどう課題にしたか

1件の指摘を、1件の Issue にしました。まとめて「UX 改善」の1本にはしていません。

- タイトル：指摘のタイトル（例：「保存しても完了表示がなく、編集画面のまま残る」）
- 本文：重要度、発生画面、環境（デスクトップ／モバイル）、再現手順、期待した動作、実際の動作、ユーザーへの影響、改善提案
- 添付：該当するスクリーンショット

1件ずつに分けたのは、

- 1件ずつ閉じられる。直ったかどうかを、その Issue の再現手順でそのまま確かめられる
- 「期待した動作」が、そのまま受け入れ条件になる
- 重要度で並べて、上から取りかかれる

からです。レポートが最初から「再現手順・期待した動作・実際の動作・スクリーンショット」の形で書かれていたので、そのまま Issue に起こせました。

## まず直すもの

最初に取りかかるのは、この5つです。どれも High の指摘で、毎日の「書く」「2人で使う」に直接かかわります。

1. 保存したら「保存しました」と出して、読む画面に戻す
2. Blame や Commit などの言葉を、ふだんの言葉に言い換える（「だれが書いた？」「書き直しの履歴」など）
3. 「今日の日記を書く」ボタンを、いつでも押せる場所に置く
4. グループのチャットを、ちゃんと開けるようにする
5. 日記を書く・読む画面に、外部広告を出さない

直ったら、note の Whatcha アカウントでお知らせします。

## おわりに

5点は、正直に言って耳の痛い点数でした。でも、作っている本人には見えない景色を、いちばん届けたい人の目線で、最初の数秒から全部見てもらえた。どんな数字よりも価値がありました。

Wさんのように「ここが分かりにくい」「こう使いたいのに、できない」があれば、ぜひ教えてください。作っている側が気づいていないことが、いちばん多いからです。
